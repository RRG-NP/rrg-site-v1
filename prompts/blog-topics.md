topic from the list below, writes that post, then marks it done. Add new topics to the bottom
any time. Keep them in the engineer-persona spirit: practical lessons, honest opinions, real
tradeoffs - and a title that earns the click without lying. Focus areas: web performance,
React Native, system design, architecture, and AI for developers.

Format: `- [ ]` = available, `- [x]` = already written. The picker matches the exact topic
text, so edit wording before it's used, not after.
